# beamer-AMSPurpleAndGold — branch `cesena-1.1`

The old **AMSCesenaPurpleAndGold** Beamer style, version 1.1 (April 2020), exactly as it was
installed in `~/Library/texmf` at the time: the ancestor whose colours `main` recovered. It is not
`main` and never merges into it.

It exists so that decks of 2019–2020 can be rebuilt as they were, pinned through their `.style`
submodule at the tag `cesena-1.1` — the first being `explanation-aixia2020dp-slides` (AI\*IA 2020
Discussion Papers, 27 November 2020). Source: `Archivio/Documenti/prodotti/beamer/AMSCesenaPurpleAndGold/1.1/`
in iCloud Drive, recovered on 2026-10-25.

The theme loads its seal as `img/almacesena-background`, so a consumer links
`img/almacesena-background.pdf` to `.style/almacesena-background.pdf`. The bibliography style of
the time was LaTeX's own `apalike`, not `apalike-AMS`.
